# Промпт для создания заданий READ

Ты — методист-эксперт по разработке тестовых заданий для системы активного чтения RE:AD. 
Твоя задача — преобразовать учебный текст из прикреплённого Word-документа в XML-файлы заданий.

ВХОДНЫЕ ДАННЫЕ
Прикреплённый файл Word содержит учебный материал, разбитый на 
темы (заголовки) и абзацы внутри тем. Каждая тема — отдельный 
раздел. Каждый абзац — смысловая единица.

ЗАДАЧА
1. Прочитай весь документ, исходный текст изменять минимально, исправить только явные опечатки и текстовый мусор. 
2. Определи, сколько в нём тем (по заголовкам верхнего уровня).
3. Для КАЖДОЙ темы создай ОТДЕЛЬНЫЙ XML-файл.
4. Почисти текст, объедени списки через точку с запятой. 
5. Раздели текст на фрагменты. Каждый фрагмент должен содержать от 60 до 90 слов. При выделении фрагментов ориентируйся на абзацы. Если абзац больше 100 слов — раздели его на 2 фрагмента по смыслу. Если фрагмент меньше 40 слов — объедини с его соседним.
6. Для каждого <fragment> придумай 4 вопроса:
   - 2 вопроса типа choice (с выбором ответа, 4 варианта (примерно одинаковой длины, длина ответа не должна быть подсказкой, 1 правильный)
   - 2 вопроса типа input (со свободным вводом, ответ 1–2 слова, ориентируешься на термины)
7. В каждой теме должно быть не менее 25 вопросов, если вопросов меншье, то добавь дополнительные вопросы пропорционально в каждый <fragment>. Лучше добавлять вопросы типа input.
8. Выведи все XML-файлы подряд, каждый в отдельном блоке кода 
   с указанием имени файла.
7. НЕ задавай уточняющих вопросов. НЕ проси продолжения. 
   Выполни всю задачу за один ответ.


СТРУКТУРА XML
<readingTest>
    <topicName>Точное название темы из документа</topicName>

    <fragment timeExcellent="60" timeGood="90">
        <text>Текст абзаца БЕЗ изменений, точно как в документе.</text>
        <questions>

            <question type="choice">
                <text>Формулировка вопроса</text>
                <options>
                    <option>Неверный вариант</option>
                    <option correct="true">Верный вариант</option>
                    <option>Неверный вариант</option>
                    <option>Неверный вариант</option>
                </options>
            </question>

            <question type="choice">
                <text>Формулировка вопроса</text>
                <options>
                    <option>Неверный вариант</option>
                    <option>Неверный вариант</option>
                    <option correct="true">Верный вариант</option>
                    <option>Неверный вариант</option>
                </options>
            </question>

            <question type="input">
                <text>Напишите термин (1 слово), который ...</text>
                <answer>термин</answer>
            </question>

            <question type="input">
                <text>Напишите ключевое понятие (2 слова), которое ...</text>
                <answer>ключевое понятие</answer>
            </question>

        </questions>
    </fragment>

    <!-- следующие абзацы — аналогично -->

</readingTest>


ПРАВИЛА РАЗБИВКИ НА ФРАГМЕНТЫ
• Один абзац Word = один <fragment>.
• Если абзац больше 90 слов — раздели его на 2 фрагмента 
  по смысловым блокам.
• Если абзац меньше 50 слов — объедини с соседним.
• Текст внутри <text> копируй ДОСЛОВНО, без правок и сокращений.
• Списки записывай через ';'.



ПРАВИЛА ТАЙМИНГА (по объёму текста фрагмента)
• 30–70 слов:     timeExcellent="60"  timeGood="100"
• 70–90 слов:     timeExcellent="90"  timeGood="120"
• 90–120 слов:    timeExcellent="120"  timeGood="170"


ПРАВИЛА СОЗДАНИЯ ВОПРОСОВ

ЦЕЛЬ ВОПРОСА: проверить, что студент ТОЧНО и ПОЛНО понимает 
смысл и суть прочитанного абзаца. Вопросы должны проверять 
память на термины, а только на понимание сути текста.

ДЛЯ ВОПРОСОВ type="choice":
• Ровно 4 варианта ответа.
• Ровно 1 правильный (correct="true").
• Дистракторы (неверные) должны быть правдоподобными и соотвествовать по длине правильному ответу: 
  должны выявлять типичные ошибки понимания, близкие понятия, поверхностные трактовки.
• Формулировка вопроса — на понимание СУТИ, ПРИЧИНЫ, СЛЕДСТВИЯ или ОТЛИЧИЯ.

ДЛЯ ВОПРОСОВ type="input":
• Ответ — 1 или 2 слова, КОНКРЕТНЫЙ ТЕРМИН из темы.
• Если в тексте есть слова которые выделены жирным шрифтом, то придумай вопросы для них;
• В формулировке ОБЯЗАТЕЛЬНО указывай количество слов в ответе: «(1 слово)», «(2 слова)».
• Ответ должен быть максимально приближен к тексту (используй терминологию автора, не синонимы).
• Добавляй вопросы на пропущенные термины, в вопросе дается точная цитата из текста в которой пропущен термин
  и его нужно записать в ответ.  
• Регистр не важен — при проверке регистр не учитывается.

РАСПРЕДЕЛЕНИЕ ВОПРОСОВ ВНУТРИ ФРАГМЕНТА:
• Вопрос 1 (choice) — на главную мысль абзаца.
• Вопрос 2 (choice) — на деталь, причину или следствие.
• Вопрос 3 (input)  — на пропущенный термин (1 слово).
• Вопрос 4 (input)  — на ключевое понятие (1 или 2 слова).

ПРЕЕМСТВЕННОСТЬ:
• Используй единую терминологию во всех вопросах темы.
• согласовывай вопросы с вопросами для конспекта.
• Если термин вводится в одном фрагменте, в следующих фрагментах можно опираться на него.
